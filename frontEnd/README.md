# FrontEnd

## Tecnologias
- React Native
- Expo
- TypeScript

## Instalação

Após clonar o projeto:

cd frontEnd

npm install

## Executar

npx expo start 

## Caso dê erro por causo do SDK58

delete o node_modules - (rm -rf node_modules)
delete o package-lock.json - (rm package-lock.json)  

rode:
npm install 
e depois da instalação:
npx expo start --clear
